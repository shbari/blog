💻 WSL2 + Ubuntu + Fortran + NetCDF

A command-by-command guide for building a complete scientific computing environment on Windows using WSL2 and Ubuntu for the RRI model.

1. What We Are Building

This tutorial creates a Linux-based scientific computing environment inside Windows using WSL2. The goal is to build a practical environment for scientific programming, especially for Fortran, NetCDF, climate data, numerical models (like RRI), GIS data, and Python.

The final environment will contain:
  • WSL2 & Ubuntu
  • GCC & GFortran
  • HDF5 & NetCDF / NetCDF-Fortran 4.6.1
  • GDAL & fortls
  • Python Stack: NumPy, pandas, xarray, Matplotlib, Cartopy, GeoPandas, Rasterio, Shapely
💡 Note: Most commands in this tutorial are executed inside the Ubuntu terminal. WSL management commands are executed from Windows PowerShell as Administrator.

2. Install WSL2 and Choose a Linux Distribution

Step 1 — Open PowerShell as Administrator

Open the Windows Start menu, search for PowerShell, right-click and select Run as administrator.

Step 2 — Install WSL

wsl --install

Step 3 — See Available Linux Distributions

wsl.exe --list --online

Step 4 — Install Ubuntu

wsl.exe --install -d Ubuntu

Step 5 — Restart Windows & Launch Ubuntu

Restart your PC if prompted, then open Ubuntu from the Start menu.

Step 6 — Set Up Unix Credentials

When prompted, enter your new UNIX username and password:

Enter new UNIX username: yourname
New password:
Retype new password:
Important: Typing password characters in Linux will not display on screen. This is normal behavior—just type and press Enter.

Step 7 — Verify WSL Version

From PowerShell, run:

wsl --list --verbose

Ensure the VERSION column displays 2.

3. Move Ubuntu to Another Drive (Optional)

If your C: drive is low on space, you can move your WSL instance to another drive.

Step 1 — Create Destination & Export

Run these commands in PowerShell as Administrator:

mkdir D:\WSLDistros\Ubuntu
wsl --export Ubuntu D:\WSLDistros\Ubuntu\ext4.vhdx --format vhd
dir D:\WSLDistros\Ubuntu
⚠️ Warning: Ensure the VHDX file exists before continuing. Unregistering is destructive!

Step 2 — Unregister and Import In-Place

wsl --unregister Ubuntu
wsl --import-in-place Ubuntu D:\WSLDistros\Ubuntu\ext4.vhdx
wsl -d Ubuntu

4. Update Ubuntu & Install Compilers

Execute all remaining commands inside your Ubuntu terminal.

Update System Packages

sudo apt update && sudo apt upgrade -y

Install Compilers & Build Tools

sudo apt install -y gcc gfortran build-essential

Verify Compiler

gfortran --version

5. Install HDF5 and NetCDF Libraries

Install HDF5 & NetCDF C-Libraries

sudo apt install -y hdf5-tools hdf5-helpers libhdf5-dev libhdf5-doc libhdf5-serial-dev libnetcdf-dev

Check NetCDF Config

nc-config --all

6. Build NetCDF-Fortran 4.6.1

We will compile NetCDF-Fortran from source for GFortran compatibility.

Download and Extract Source

mkdir -p ~/Downloads && cd ~/Downloads
wget https://downloads.unidata.ucar.edu/netcdf-fortran/4.6.1/netcdf-fortran-4.6.1.tar.gz
tar xf netcdf-fortran-4.6.1.tar.gz
cd netcdf-fortran-4.6.1

Configure, Build, and Install

./configure --prefix=/usr/local/netcdf-gfortran/4.6.1 --enable-large-file-tests --with-pic
make
make check
sudo make install

Configure Environment Variables

echo '' >> ~/.bashrc
echo '# NetCDF-Fortran using GFortran' >> ~/.bashrc
echo 'export PATH="/usr/local/netcdf-gfortran/4.6.1/bin:$PATH"' >> ~/.bashrc
echo 'export LD_LIBRARY_PATH="/usr/local/netcdf-gfortran/4.6.1/lib:$LD_LIBRARY_PATH"' >> ~/.bashrc
source ~/.bashrc

Verify NetCDF-Fortran

nf-config --all

7. Install Utilities & Fortran Language Server

Command-Line Tools

sudo apt install -y netcdf-bin gdal-bin bc unar curl sed nkf

Install fortls for VS Code

sudo apt install -y python3 python3-pip
python3 -m pip install fortls
fortls --version

8. Install Python Scientific Stack

python3 -m pip install xarray numpy pandas matplotlib cartopy geopandas rasterio shapely

NumPy & pandas

Numerical computing, matrices, and tabular data analysis.

xarray

Multidimensional scientific arrays and NetCDF file handling.

Matplotlib & Cartopy

Data visualization and mapping geographic features.

GeoPandas & Rasterio

Handling vector and raster GIS datasets efficiently.

9. Verification & Next Steps

Run Verification Suite

gcc --version
gfortran --version
nc-config --all
nf-config --all
python3 -c "import numpy, pandas, xarray, matplotlib, cartopy, geopandas, rasterio, shapely; print('All Python packages imported successfully.')"
🚀 Success! Your scientific modeling environment is fully prepared. Next, write a small test Fortran program that links against NetCDF-Fortran to verify compilation settings for your RRI model.
