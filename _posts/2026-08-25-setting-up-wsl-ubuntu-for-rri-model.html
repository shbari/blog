A command-by-command guide for building a scientific computing environment for RRI (Rainfall-Runoff-Inundation) model on Windows using WSL2 and Ubuntu.

1. What We Are Building

This tutorial creates a Linux-based scientific computing environment inside Windows using WSL2.

The goal is to create a practical environment for running RRI model using CUI. This is also useful for other scientific computing tasks especilly in climate change and hydrology.

Important: Most commands in this tutorial are executed inside the Ubuntu terminal. WSL management commands are executed from Windows PowerShell.

2. Install WSL2 and Choose a Linux Distribution

WSL2 allows you to run a Linux environment directly inside Windows. For this tutorial, we will use Ubuntu.

Step 1 — Open PowerShell as Administrator

Open the Windows Start menu and search for PowerShell. Right-click PowerShell and select Run as administrator.

Step 2 — Install WSL

Run the following command:

wsl --install

By default, WSL installs Ubuntu as the default Linux distribution. For RRI model, I recommend Ubuntu-22.04 since compatibility is already tested.

Step 3 — See Available Linux Distributions

To see the Linux distributions currently available for installation, run: 

wsl.exe --list --online

Step 4 — Install a Specific Distribution

You can choose a distribution using the -d option: 

wsl.exe --install -d [Distro]

Replace [Distro] with the name of the distribution you want to install.

For example, to install Ubuntu-22.04:

wsl.exe --install -d Ubuntu-22.04
Important notice: The remaining commands [starting from step 7] are written for an Ubuntu environment.

Step 5 — Restart Windows

Restart your computer if Windows asks you to do so.

Step 6 — Start Ubuntu

After restarting Windows, open Ubuntu from the Start menu.

The first launch may take a few moments while Ubuntu completes its initial setup.

Step 7 — Create Your Linux Username

Ubuntu will ask you to create a Linux user account. Enter the username you would like to use. 

Enter new UNIX username: yourname

Your Linux username does not need to be the same as your Windows username.

Step 8 — Create Your Linux Password

Ubuntu will then ask you to create a password. Please remember this password, as you will need it in the future to run commands with administrative privileges. 

New password:
Retype new password:
Important: When you type your password in the Linux terminal, the characters will not appear on the screen. This is normal. Type your password and press Enter.

Step 9 — Check the WSL Installation

Open PowerShell and run: 

wsl --list --verbose

You should see your installed Linux distribution in the list.

Check the VERSION column. Your distribution should show version 2.

Installing a Distribution Not Listed by WSL

WSL can also work with Linux distributions that are not included in the standard online list.

Advanced users can import a Linux distribution from a TAR archive. Some distributions can also be installed using an .appx package.

It is also possible to create a custom Linux distribution for WSL.

For this tutorial: You do not need these advanced installation methods. A standard Ubuntu installation is sufficient.

Troubleshooting WSL Installation

If you encounter an installation problem, consult Microsoft's official WSL troubleshooting documentation for installation issues.

3. Move Ubuntu to Another Drive

If your Windows system drive is running out of space, you can move your WSL distribution to another drive.

Warning: The wsl --unregister command is destructive. It removes the existing WSL distribution. Make sure your export completed successfully before using it.

Step 1 — Create a Destination Folder. We will use 'D' drive as an example:

Open PowerShell as Administrator:

mkdir D:\WSLDistros

Step 2 — Export Ubuntu

Export Ubuntu to the new drive:

wsl --export Ubuntu D:\WSLDistros\ext4.vhdx --format vhd

Step 3 — Verify the Export

dir D:\WSLDistros
Do not continue if the export failed. Make sure the VHDX file exists before unregistering Ubuntu.

Step 4 — Unregister the Original Ubuntu

wsl --unregister Ubuntu

Step 5 — Import Ubuntu at the New Location

wsl --import-in-place Ubuntu D:\WSLDistros\ext4.vhdx

Step 6 — Start Ubuntu

wsl -d Ubuntu
Done! Ubuntu is now running from its new storage location. You can also run Ubuntu from the Start menu as before.

5. Install GCC and GFortran

GCC is the GNU Compiler Collection. GFortran is the GNU Fortran compiler.

Install GCC

sudo apt install -y gcc

Install GFortran

sudo apt install -y gfortran

Install Build Tools

sudo apt install -y build-essential

Check GFortran

gfortran --version

6. Install HDF5 and NetCDF Libraries

NetCDF is widely used for storing scientific datasets. HDF5 is an important underlying data format used by NetCDF-4.

Install HDF5 Packages

sudo apt install -y hdf5-tools hdf5-helpers libhdf5-dev libhdf5-doc libhdf5-serial-dev

Install NetCDF Development Libraries

sudo apt install -y libnetcdf-dev

Check NetCDF Configuration

nc-config -all
↑ Back to top

7. Build NetCDF-Fortran 4.6.1

NetCDF-Fortran provides the Fortran interface to NetCDF. We will download the source code, compile it with GFortran, test it, and install it.

Step 1 — Create a Downloads Directory

mkdir -p ~/Downloads

Step 2 — Enter the Downloads Directory

cd ~/Downloads

Step 3 — Download NetCDF-Fortran 4.6.1

wget https://downloads.unidata.ucar.edu/netcdf-fortran/4.6.1/netcdf-fortran-4.6.1.tar.gz

Step 4 — Extract the Archive

tar xf netcdf-fortran-4.6.1.tar.gz

Step 5 — Enter the Source Directory

cd netcdf-fortran-4.6.1

Step 6 — Configure the Build

We will install NetCDF-Fortran under /usr/local/netcdf-gfortran/4.6.1. 

./configure --prefix=/usr/local/netcdf-gfortran/4.6.1 --enable-large-file-tests --with-pic

Step 7 — Compile NetCDF-Fortran

make

Step 8 — Run the Test Suite

make check
Tip: If the test finish successfully, this is a good indication that NetCDF-Fortran was compiled correctly.

Step 9 — Install NetCDF-Fortran

sudo make install
↑ Back to top

8. Configure the NetCDF Environment

Linux needs to know where the NetCDF-Fortran executable files and shared libraries are located.

Add NetCDF to PATH

echo '' >> ~/.bashrc
echo '# NetCDF-Fortran using GFortran' >> ~/.bashrc
echo 'export PATH="/usr/local/netcdf-gfortran/4.6.1/bin:$PATH"' >> ~/.bashrc
echo 'export LD_LIBRARY_PATH="/usr/local/netcdf-gfortran/4.6.1/lib:$LD_LIBRARY_PATH"' >> ~/.bashrc

Reload Your Shell Configuration

source ~/.bashrc

Check NetCDF-Fortran

nf-config --all
↑ Back to top

11. Install Miniforge and Python Scientific Libraries

Miniforge is optional for running the RRI model itself. However, it is recommended if you want to use Python for NetCDF analysis, visualization, and GIS processing.

Important: Miniforge is not required to compile or run RRI. The RRI compilation environment is provided by GFortran, HDF5, NetCDF-C, and NetCDF-Fortran installed in the previous steps.

Miniforge provides a convenient way to create isolated Python environments and install scientific Python packages from conda-forge. This avoids modifying Ubuntu's system Python environment.

Step 1 — Download Miniforge

Download the latest Miniforge installer for Linux from the official conda-forge website. For most WSL2 Ubuntu installations, use the Linux x86_64 (amd64) installer.

You can download it directly from the Ubuntu terminal: 

curl -L -O "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-Linux-x86_64.sh"

Verify that the installer was downloaded: 

ls -lh Miniforge3-Linux-x86_64.sh

Step 2 — Install Miniforge

Make the installer executable: 

chmod +x Miniforge3-Linux-x86_64.sh

Run the installer: 

./Miniforge3-Linux-x86_64.sh

Follow the instructions displayed by the installer. When asked whether to initialize Miniforge, choose yes.

Step 3 — Reload the Shell

source ~/.bashrc

Step 4 — Check Conda

conda --version
Tip: If conda is not found, close and reopen the Ubuntu terminal, then run conda --version again.

Step 5 — Create an RRI Python Environment

Create a separate environment for the Python tools used with RRI: 

conda create -n rri python=3.12

Step 6 — Activate the RRI Python Environment

conda activate rri

Step 7 — Install Scientific Python Packages

Install the main packages used for scientific analysis, NetCDF processing, visualization, and GIS: 

conda install -c conda-forge numpy pandas xarray matplotlib cartopy geopandas rasterio shapely

Step 8 — Check Python

python --version

Step 9 — Test the Python Packages

python -c "import numpy, pandas, xarray, matplotlib, cartopy, geopandas, rasterio, shapely; print('All Python packages imported successfully.')"
Tip: Whenever you want to use these Python packages, activate the environment with conda activate rri.

12. Optional — Install fortls for VS Code

fortls is a Fortran Language Server. It is not required to compile or run RRI. If you use VS Code for Fortran development, fortls can provide features such as code completion, symbol navigation, hover information, and diagnostics.

Optional: Skip this section if you only need to compile and run RRI.

Install fortls in the RRI Python Environment

First activate the Miniforge environment created in the previous section: 

conda activate rri

Install fortls: 

python -m pip install fortls

Check fortls

fortls --version
VS Code: If VS Code cannot find fortls automatically, configure the Fortran language server to use the executable located in the rri environment.
