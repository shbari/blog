1. What We Are Building

This tutorial creates a Linux-based scientific computing environment inside Windows using WSL2.

The goal is to create a practical environment for scientific programming, especially for Fortran, NetCDF, climate data, numerical models, GIS data, and Python.

The final environment will contain:
  • WSL2
  • Ubuntu
  • GCC
  • GFortran
  • HDF5
  • NetCDF
  • NetCDF-Fortran 4.6.1
  • GDAL
  • fortls
  • Python
  • NumPy
  • pandas
  • xarray
  • Matplotlib
  • Cartopy
  • GeoPandas
  • Rasterio
  • Shapely
Important: Most commands in this tutorial are executed inside the Ubuntu terminal. WSL management commands are executed from Windows PowerShell.

2. Install WSL2 and Choose a Linux Distribution

WSL2 allows you to run a Linux environment directly inside Windows. For this tutorial, we will use Ubuntu.

Step 1 — Open PowerShell as Administrator

Open the Windows Start menu and search for PowerShell. Right-click PowerShell and select Run as administrator.

Step 2 — Install WSL

Run the following command:

wsl --install

By default, WSL installs Ubuntu as the default Linux distribution.

Step 3 — See Available Linux Distributions

To see the Linux distributions currently available for installation, run: 

wsl.exe --list --online

Step 4 — Install a Specific Distribution

You can choose a distribution using the -d option: 

wsl.exe --install -d [Distro]

Replace [Distro] with the name of the distribution you want to install.

For example, install Ubuntu:

wsl.exe --install -d Ubuntu
Recommendation: Use Ubuntu for this tutorial. The remaining commands are written for an Ubuntu environment.

Step 5 — Restart Windows

Restart your computer if Windows asks you to do so.

Step 6 — Start Ubuntu

After restarting Windows, open Ubuntu from the Start menu.

The first launch may take a few moments while Ubuntu completes its initial setup.

Step 7 — Create Your Linux Username

Ubuntu will ask you to create a Linux user account. Enter the username you would like to use. 

Enter new UNIX username: yourname

Your Linux username does not need to be the same as your Windows username.

Step 8 — Create Your Linux Password

Ubuntu will then ask you to create a password: 

New password:
Retype new password:
Important: When you type your password in the Linux terminal, the characters will not appear on the screen. This is normal. Type your password and press Enter.

Step 9 — Check the WSL Installation

Open PowerShell and run: 

wsl --list --verbose

You should see your installed Linux distribution in the list.

Check the VERSION column. Your distribution should show version 2.

Installing a Distribution Not Listed by WSL

WSL can also work with Linux distributions that are not included in the standard online list.

Advanced users can import a Linux distribution from a TAR archive. Some distributions can also be installed using an .appx package.

It is also possible to create a custom Linux distribution for WSL.

For this tutorial: You do not need these advanced installation methods. A standard Ubuntu installation is sufficient.

Troubleshooting WSL Installation

If you encounter an installation problem, consult Microsoft's official WSL troubleshooting documentation for installation issues.

3. Move Ubuntu to Another Drive

If your Windows system drive is running out of space, you can move your WSL distribution to another drive.

Warning: The wsl --unregister command is destructive. It removes the existing WSL distribution. Make sure your export completed successfully before using it.

Step 1 — Create a Destination Folder

Open PowerShell as Administrator:

mkdir D:\WSLDistros\Ubuntu

Step 2 — Export Ubuntu

Export Ubuntu to the new drive:

wsl --export Ubuntu D:\WSLDistros\Ubuntu\ext4.vhdx --format vhd

Step 3 — Verify the Export

dir D:\WSLDistros\Ubuntu
Do not continue if the export failed. Make sure the VHDX file exists before unregistering Ubuntu.

Step 4 — Unregister the Original Ubuntu

wsl --unregister Ubuntu

Step 5 — Import Ubuntu at the New Location

wsl --import-in-place Ubuntu D:\WSLDistros\Ubuntu\ext4.vhdx

Step 6 — Start Ubuntu

wsl -d Ubuntu
Done! Ubuntu is now running from its new storage location.

6. Install HDF5 and NetCDF Libraries

NetCDF is widely used for storing scientific datasets. HDF5 is an important underlying data format used by NetCDF-4.

Install HDF5 Packages

sudo apt install -y hdf5-tools hdf5-helpers libhdf5-dev libhdf5-doc libhdf5-serial-dev

Install NetCDF Development Libraries

sudo apt install -y libnetcdf-dev

Check NetCDF Configuration

nc-config --all

7. Build NetCDF-Fortran 4.6.1

NetCDF-Fortran provides the Fortran interface to NetCDF. We will download the source code, compile it with GFortran, test it, and install it.

Step 1 — Create a Downloads Directory

mkdir -p ~/Downloads

Step 2 — Enter the Downloads Directory

cd ~/Downloads

Step 3 — Download NetCDF-Fortran 4.6.1

wget https://downloads.unidata.ucar.edu/netcdf-fortran/4.6.1/netcdf-fortran-4.6.1.tar.gz

Step 4 — Extract the Archive

tar xf netcdf-fortran-4.6.1.tar.gz

Step 5 — Enter the Source Directory

cd netcdf-fortran-4.6.1

Step 6 — Configure the Build

We will install NetCDF-Fortran under /usr/local/netcdf-gfortran/4.6.1. 

./configure --prefix=/usr/local/netcdf-gfortran/4.6.1 --enable-large-file-tests --with-pic

Step 7 — Compile NetCDF-Fortran

make

Step 8 — Run the Test Suite

make check
Tip: If the tests finish successfully, this is a good indication that NetCDF-Fortran was compiled correctly.

Step 9 — Install NetCDF-Fortran

sudo make install
↑ Back to top

8. Configure the NetCDF Environment

Linux needs to know where the NetCDF-Fortran executable files and shared libraries are located.

Add NetCDF to PATH

echo '' >> ~/.bashrc
echo '# NetCDF-Fortran using GFortran' >> ~/.bashrc
echo 'export PATH="/usr/local/netcdf-gfortran/4.6.1/bin:$PATH"' >> ~/.bashrc
echo 'export LD_LIBRARY_PATH="/usr/local/netcdf-gfortran/4.6.1/lib:$LD_LIBRARY_PATH"' >> ~/.bashrc

Reload Your Shell Configuration

source ~/.bashrc

Check NetCDF-Fortran

nf-config --all

10. Install fortls for VS Code

fortls is a Fortran Language Server. It provides features such as code completion, symbol navigation, and diagnostics for Fortran development.

Install Python and pip

sudo apt install -y python3 python3-pip

Install fortls

python3 -m pip install fortls

Check fortls

fortls --version
↑ Back to top

11. Install Python Scientific Libraries

Python is useful for analyzing NetCDF files, creating plots, manipulating tabular data, and working with geospatial datasets.

Install the Scientific Python Packages

python3 -m pip install xarray numpy pandas matplotlib cartopy geopandas rasterio shapely

What Do These Packages Do?

  • NumPy — numerical computing and arrays
  • pandas — tabular data analysis
  • xarray — multidimensional scientific datasets
  • Matplotlib — plotting and visualization
  • Cartopy — geographic and map visualization
  • GeoPandas — geospatial vector data
  • Rasterio — raster and geospatial data
  • Shapely — geometric operations
Note about modern Ubuntu: Some newer Ubuntu versions prevent direct installation of Python packages into the system Python environment. If you encounter an externally-managed-environment error, use a Python virtual environment instead.

12. Verify the Installation

At this point, verify that the main components are available.

Check GCC

gcc --version

Check GFortran

gfortran --version

Check NetCDF C

nc-config --all

Check NetCDF-Fortran

nf-config --all

Check Python

python3 --version

Check Python Packages

python3 -c "import numpy, pandas, xarray, matplotlib, cartopy, geopandas, rasterio, shapely; print('All Python packages imported successfully.')"
Success! If the commands above complete without errors, your basic scientific computing environment is ready.

13. What's Next?

Your Windows computer now has a Linux-based scientific computing environment through WSL2.

A typical workflow might look like this:

  1. Write and compile Fortran programs with GFortran.
  2. Read and write NetCDF files using NetCDF-Fortran.
  3. Process NetCDF data using Python and xarray.
  4. Create scientific plots with Matplotlib.
  5. Visualize geographic data with Cartopy.
  6. Process GIS data using GDAL, GeoPandas, Rasterio, and Shapely.
  7. Use VS Code as your development environment.
Recommended next step: Create a small test Fortran program that links against NetCDF-Fortran. This will confirm that the compiler, NetCDF libraries, include files, and linker settings are all working together.
